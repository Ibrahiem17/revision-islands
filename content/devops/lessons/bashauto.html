🧩 The Shape Every One of These Follows
Before the 5 scripts — notice this same pattern repeats in every single one below. Once it clicks, nothing here feels random.
1
Say what and wherevariables, near the top
The folder, the file, the number — whatever this script is actually about, named clearly in a variable right at the top. Change the task by changing these lines, never the logic below.
2
Make sure it's safe to continuea quick check, before acting
Does the folder exist? Is a number actually a number? A small check here means the script stops cleanly instead of doing something wrong somewhere it shouldn't.
3
Do the actual thingthe one line that matters
Every script here really has just one or two lines doing the real work — moving a file, deleting old ones, copying a folder. Everything else exists to set that line up safely.
4
Say what happenedecho, at the end
A script that finishes silently leaves you wondering if it worked. One friendly line at the end removes all the doubt.
