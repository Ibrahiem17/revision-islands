🔒 DevSecOps — Security Baked Into the Pipeline
DevSecOps = security integrated throughout the development and deployment process — not bolted on at the end. Security at every stage, automated in the pipeline.
⬅️Shift Left SecuritySAST / Lint
Perform security checks early — static code analysis, dependency scanning, secret detection during the build phase. Catch vulnerabilities at commit, not in production.
🤖Automated Security TestsDAST / Snyk
Vulnerability scans and dynamic application security testing (DAST) run automatically in CI. Identify issues before they reach production.
📊Continuous MonitoringPrometheus / Grafana
Monitor pipeline and deployed apps for security incidents. Use specialized security monitoring tools alongside Prometheus/Grafana.
🏗️IaC Security ScanningCheckov / tfsec
Scan Terraform/CloudFormation templates for misconfigurations and vulnerabilities (like hardcoded passwords, overly permissive policies) before they're applied.
🔑Access ControlRBAC / IAM
Strict access controls using RBAC (Role-Based Access Control) or ABAC. Enforce least privilege principle across the entire pipeline — humans and services.
🚨Incident ResponsePagerDuty / Alerts
Clear incident response plan integrated into the pipeline. Security alerts fire automatically. Quickly address potential breaches. Runbooks for common scenarios.
🔀 Reverse Proxy — Nginx
A reverse proxy sits between clients and backend servers, forwarding requests to the appropriate server and returning responses to the client.

What it provides:
• Load balancing — distribute requests across backend servers
• SSL termination — handle HTTPS at the proxy, HTTP behind it
• Caching — serve cached responses without hitting backends
• Security — hide backend server IPs, rate limiting, WAF

Example (Nginx): Web app on 3 backend servers. Nginx distributes incoming HTTP requests evenly. If one server fails, Nginx routes around it. SSL cert lives on Nginx — backends don't need it.
