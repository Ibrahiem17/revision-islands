🏛️ The .git Directory — What's Inside
PATHWHAT IT STORES
.git/objects/All commits, trees (directories), blobs (file versions) as SHA-1 hashed files. Every version of every file ever committed.
.git/refs/Branches and tags are just files containing a commit hash. refs/heads/main = SHA of latest main commit.
.git/HEADPoints to current branch. Usually: ref: refs/heads/main. In detached state: direct commit hash.
.git/indexThe staging area. git add puts changes here. What Git compares against during git status.
.git/configRepo-level config: remote URLs, branch tracking, user settings.
.git/hooks/Scripts that run at Git events: pre-commit, commit-msg, pre-push, post-receive.
🔍 git bisect — Binary Search for Bugs
Problem: A bug exists. 500 commits could have introduced it.
Solution: Mark "bad" commit + "good" commit. Git checks midpoint. You test. Git narrows down. Finds culprit in ~9 steps instead of 500.
git bisect start
git bisect bad               # current commit has bug
git bisect good v2.1.0       # v2.1.0 was clean
# → Git checks out midpoint. You test.
git bisect bad               # still has bug
git bisect good              # no bug here
# → Repeat until: "first bad commit is a3f9d2c"
git bisect reset             # end session
🌿 Branching Strategies
Git Flow
Main branches: main + develop. Supporting: feature/, release/, hotfix/.

Good for: Scheduled releases, larger teams, versioned/packaged software.
Trunk-Based Development
Single main branch. Short-lived feature branches (merged within hours). Feature flags hide incomplete work. Google/Netflix/Facebook model.

Good for: Continuous deployment, SaaS products.

⚙️ Configuration Management (Ansible)
PlaybookYAML config
YAML file declaring desired state across servers. "Nginx should be installed and running. User deploy_bot should exist."
Inventorytarget list
File listing servers Ansible should manage. Group them: [web], [db]. Run playbooks against specific groups.
Idempotentsafe to repeat
Run the same playbook 10 times = same result as once. If Nginx is already installed, Ansible skips it.
AgentlessSSH only
No agent to install. Connects via SSH, runs tasks, disconnects. Works with any server that has Python + SSH.
