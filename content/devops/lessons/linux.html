📁 Navigation & File Management
pwdlocation
Print working directory — shows where you are right now.
$ pwd
/home/ibrahiem
ls -lalist
ls lists files. -l = long format (permissions, size, date). -a = show hidden files (starting with .).
$ ls -la /var/log
cd /var/lognavigate
Change directory. cd .. = go up one level. cd ~ = go home. cd - = go back to previous dir.
$ cd /var/log
$ cd ..
touch / mkdircreate
touch app.log creates an empty file. mkdir logs creates a folder. mkdir -p app/config creates nested dirs in one shot.
$ touch app.log
$ mkdir -p app/config
cp / mv / rmmanage
cp file.txt backup.txt copies. cp -r dir1 dir2 copies directories. mv old.txt new.txt renames or moves. rm -rf folder deletes folder recursively — no confirmation, no undo.
$ cp -r dir1 dir2
$ rm -rf folder ⚠️
📄 Reading Files
cat file.txtread all
Dump entire file to terminal. Good for small files. Avoid on huge log files.
head / tailpartial read
head -n 10 file.txt = first 10 lines. tail -n 10 file.txt = last 10 lines. tail -f app.log = follow live — watches the file as new lines are written. 🔥 Essential for watching logs in real time.
$ tail -f app.log  # live stream
grepsearch
grep "error" app.log — find lines with "error". -i = case insensitive. -r = search recursively through all files in a directory.
$ grep -i "error" app.log
$ grep -r "error" .
findlocate files
Search the filesystem by name or type. find . -name "*.log" = all .log files in current dir. find / -type f -name "config.yaml" = search entire filesystem.
$ find . -name "*.log"
$ find / -type f -name "config.yaml"
🔗 Pipes & Redirects — The Power Combo
Pipe ( | ) = take the output of one command and feed it as input to the next.
Redirect ( > ) = send output to a file (overwrites). ( >> ) = append to file.
ls | grep ".txt"pipe
List files, then filter to only show .txt files. Output of ls is piped into grep.
grep "error" app.log | wc -lcount
Count how many lines contain "error". wc -l counts lines. Useful for quick error counts.
$ grep "error" app.log | wc -l
42
> and >>redirect
echo "hello" > file.txt — overwrites the file with "hello". echo "world" >> file.txt — appends "world" as a new line. > destroys existing content. >> is safe.
$ echo "hello" > file.txt
$ echo "world" >> file.txt
🔐 Permissions
Reading permission strings:
-rwxr-xr--

- = file type (-=file, d=dir, l=symlink)
rwx = owner can Read, Write, Execute
r-x = group can Read, Execute (no write)
r-- = others can only Read

Numeric mode: r=4, w=2, x=1. Add them up per group.
755 = owner:rwx(7) group:r-x(5) others:r-x(5)
644 = owner:rw-(6) group:r--(4) others:r--(4)
chmodchange perms
chmod 755 script.sh = set numeric permissions. chmod +x script.sh = add execute permission for everyone. Scripts need +x to run.
$ chmod +x deploy.sh
$ ./deploy.sh
chownchange owner
chown user file.txt = change owner. chown user:group file.txt = change both owner and group. Used when files are created by root but need to be accessed by app user.
$ chown deploy:www-data /var/app
⚙️ Processes & System Health
ps auxprocesses
List all running processes with PID, CPU%, MEM%, and command. Pipe to grep to find a specific process: ps aux | grep nginx.
$ ps aux | grep nginx
top / htoplive monitor
Live CPU/memory monitor. Updates in real time. Press q to quit. htop is the prettier version (if installed). Essential for spotting runaway processes.
kill / kill -9stop process
kill PID = graceful stop (lets process clean up). kill -9 PID = force kill instantly — no cleanup. Use graceful first, -9 as last resort.
$ kill 1234
$ kill -9 1234  # nuclear option
df -hdisk space
Show disk space on all filesystems. -h = human readable (GB/MB). Critical for catching "disk full" issues before they crash your app.
$ df -h
Filesystem Size Used Avail Use%
du -sh *folder sizes
Show size of each file/folder in current directory. du -sh /var/log/* = see which log files are eating your disk.
$ du -sh /var/log/*
free -hRAM
Show total, used, and free RAM. -h = human readable. Critical metric — if RAM is full, apps start crashing or swapping to disk (very slow).
$ free -h
Mem: 7.7G 4.2G 1.2G
uptimesystem age
Shows how long the system has been running + load average (1m, 5m, 15m). Load avg > number of CPU cores = system is overloaded.
$ uptime
up 14 days, load avg: 0.5 0.4 0.3
🌐 Networking
pingreachability
Check if a host is reachable. ping google.com sends ICMP packets and measures round-trip time. Ctrl+C to stop.
curlHTTP requests
Make HTTP requests from the terminal. Essential for testing APIs. curl http://api.com = GET request. Add -v for verbose output, -X POST for POST.
$ curl -v http://localhost:8080/health
wgetdownload
Download files from URLs. wget file_url saves to current directory. Good for downloading configs, binaries, or scripts onto a server.
🔧 Services (systemctl)
systemctl statuscheck
systemctl status nginx — shows if the service is running, failed, or stopped. Also shows last few log lines. First thing to run when something seems broken.
$ systemctl status nginx
● nginx.service - Active: active (running)
systemctl restartrestart
systemctl restart nginx — stops and restarts the service. systemctl stop / start available too. systemctl enable nginx = auto-start on boot.
$ systemctl restart nginx
$ systemctl enable nginx
