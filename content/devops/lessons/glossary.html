📖 Quick Reference — All Key Terms
CI
Auto-build + test on every push. Catch bugs early.
CD (Delivery)
Every passing build is deployable. Human approves final push.
CD (Deployment)
Every passing build auto-deploys. Fully automated.
Webhook
HTTP push notification when an event fires (e.g. git push).
Docker Image
Portable snapshot: app + all dependencies. Immutable.
Container
A running instance of a Docker image. Isolated, lightweight.
Registry
Storage for Docker images. Docker Hub, AWS ECR, GCR.
Kubernetes (K8s)
Orchestrates containers — scheduling, scaling, self-healing.
Pod
Smallest K8s unit. Wraps one or more containers.
Deployment (K8s)
Manages replicas of a pod. Handles rolling updates.
Rolling Update
Replace containers gradually. Zero downtime.
Blue-Green
Two identical envs. Flip traffic switch. Instant rollback.
Canary Deploy
Route X% of traffic to new version. Validate before full rollout.
IaC
Infrastructure described in code. Stored in Git. Repeatable.
Terraform
IaC tool. Declare infra in HCL files. Works across clouds.
Makefile
Automates build commands. make build → docker build + run.
Prometheus
Scrapes and stores time-series metrics from your app.
Grafana
Visualizes Prometheus data into dashboards + alerts.
Microservices
App split into small independent services, each in its own container.
Staging
Pre-production environment. Mirrors prod. Where CD deploys first.
Jira
Project planning tool. Tracks sprints, tickets, epics.
4 Golden Signals
Latency, Traffic, Errors, Saturation — Google SRE monitoring framework.
