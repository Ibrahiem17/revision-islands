🔐 Permissions & Ownership

adduser usernameusersCreate new user interactively. useradd -m -s /bin/bash user = non-interactive version.
usermod -aG sudo userusersAdd user to a group. -a=append (don't remove from other groups), -G=group. Essential for granting sudo access.
passwd usernameusersChange user password. Run as root to change any user's password.

🔑 SSH — Secure Shell Remote Access
CommandCategoryWhat it does & how to use it
ssh user@hostconnectConnect to remote server. Uses default key (~/.ssh/id_rsa) or password. ssh ubuntu@54.12.34.56
ssh -i key.pem user@hostconnectConnect with specific key file. Required for AWS EC2. Always chmod 400 key.pem first or SSH rejects it.
ssh -p 2222 user@hostconnectConnect on non-default port. Default SSH port is 22. Some servers use custom ports for security.
ssh-keygen -t ed25519keygenGenerate new SSH key pair. ed25519 is modern and secure. -t rsa -b 4096=RSA (older but universal). Creates public + private key.
ssh-copy-id user@hostsetupCopy your public key to server's authorized_keys. After this, passwordless login works. Requires password auth enabled first.
cat ~/.ssh/id_ed25519.pubinspectPrint your public key. Paste this into GitHub, AWS, or server authorized_keys to enable key-based auth.
ssh-add ~/.ssh/id_ed25519agentAdd key to SSH agent (so you don't re-enter passphrase). ssh-add -l=list added keys.
scp file.txt user@host:~transferSecure copy file to remote server. scp -r dir/ user@host:/path/=copy directory. scp user@host:file.txt .=download from server.
rsync -avz src/ user@h:dst/transferEfficient sync. Only transfers changed files. -a=archive (preserve permissions), -v=verbose, -z=compress. Better than scp for large directories.
ssh -L 8080:localhost:80 htunnelLocal port forwarding. Tunnel remote port 80 to your local 8080. Access internal services through firewall.
ssh -N -f -L tunneltunnel-N=no remote command, -f=background. Create background tunnel without interactive shell.
💡 ~/.ssh/config — create this file to save connection aliases:
Host myserver
  HostName 54.12.34.56
  User ubuntu
  IdentityFile ~/.ssh/my-key.pem
Now just run ssh myserver instead of the full command every time.
⌨️ Bash Scripting Essentials Automation
Command / SyntaxCategoryWhat it does & how to use it
#!/bin/bashshebangFirst line of every bash script. Tells the OS which interpreter to use. Without it, the script may run in sh (different behavior).
chmod +x script.shexecuteMake script executable. Then run with ./script.sh. Or run without chmod: bash script.sh.
set -euo pipefailsafetyPut at top of scripts. -e=exit on any error, -u=error on undefined variable, -o pipefail=catch errors in pipes. Production scripts always have this.
VAR="value"variableSet variable. No spaces around =. Access with $VAR or ${VAR}. ${VAR:-default}=use default if unset.
export VAR="value"variableExport variable to child processes. Without export, only current shell sees it.
echo "text $VAR"outputPrint text. echo -n=no newline. echo -e "\n"=interpret escape sequences. Use for debug output in scripts.
if [ "$X" == "y" ]; thenconditionIf statement. Spaces inside [ ] are required. -eq=numeric equal, -z=string empty, -f=file exists, -d=dir exists.
[[ "$X" == "y" ]]conditionDouble brackets — safer, supports regex. Use [[ ]] in bash scripts instead of [ ]. [[ "$s" =~ ^[0-9]+$ ]]=regex match.
for i in 1 2 3; doloopFor loop. for f in *.log; do echo "$f"; done. for i in {1..5}=range. for i in $(cat hosts.txt)=loop over file lines.
while [ condition ]loopWhile loop. while true; do check; sleep 5; done=polling loop. Common for health checks.
function name() { }functionDefine function. Call it by name. $1 $2=positional args. $@=all args. $#=arg count.
$(command)subshellCommand substitution — capture output. DATE=$(date +%F)=store today's date. echo "Pods: $(kubectl get pods | wc -l)"
read -r varnameinputRead user input into variable. read -p "Enter name: " NAME. -r=raw (don't interpret backslashes).
exit 0 / exit 1controlExit script with code. 0=success, non-zero=error. CI/CD systems check exit codes — a non-zero exit fails the pipeline step.
trap 'cleanup' EXITcontrolRun cleanup function on exit (even on error). Use to delete temp files, stop services, send notifications when script ends.
source ./file.shimportLoad another script in current shell (so its variables/functions become available). . ./file.sh is the same.
logger "message"loggingWrite to system log (/var/log/syslog). Use in cron jobs so output is preserved in system logs.

🌿 Branching & Merging
CommandCategoryWhat it does & how to use it
git branchbranchList local branches. git branch -a=all including remote. git branch -d name=delete branch. git branch name=create without switching.
git checkout -b feature/xbranchCreate and switch to new branch. git switch -c feature/x=modern equivalent. Always branch from updated main.

git cherry-pick abc1234cherry-pickApply a single commit from another branch onto current branch. Hotfix use case: cherry-pick a fix from develop to main without merging all of develop.
🔄 Remote Operations
CommandCategoryWhat it does & how to use it

git pull origin mainsyncFetch + merge in one step. git pull --rebase=fetch + rebase (cleaner history). Use before starting work each day.
git push origin feature/xpushPush branch to remote. git push -u origin branch=set upstream (then just git push). git push --force-with-lease=safe force push after rebase.

⏪ Undoing & Recovery
CommandCategoryWhat it does & how to use it
git reset --soft HEAD~1undoUndo last commit, keep changes staged. Useful to re-commit with different message.
git reset --mixed HEAD~1undoUndo last commit, keep changes unstaged. Default reset behavior.
git reset --hard HEAD~1undoUndo last commit, DISCARD all changes. Destructive — files are gone. Use git reflog to recover if needed.
git revert abc1234undoCreate new commit that undoes a previous commit. Safe — doesn't rewrite history. Use on shared/main branches.
git stashstashSave dirty working state temporarily. git stash pop=restore. git stash list=see all stashes. git stash drop=delete stash.
git stash push -m "name"stashStash with a descriptive name. Makes it easy to find later with git stash list.
git reflogrecoveryLog of ALL HEAD movements — even after hard reset. Your last resort for recovering "deleted" commits. Find the SHA, then git checkout SHA.
git clean -fdcleanDelete untracked files and directories. -n=dry run (preview what will be deleted). Irreversible.

📡 Prometheus & Monitoring CLI Observability
Command / QueryCategoryWhat it does & how to use it
promtool check config prometheus.ymlvalidateValidate prometheus.yml syntax before applying. Run in CI to catch config errors before deployment.
promtool check rules rules.ymlvalidateValidate alert rule files. Catches PromQL syntax errors in rules before they reach production.
curl localhost:9090/-/reloadmanageHot-reload Prometheus config without restart. Must start Prometheus with --web.enable-lifecycle flag first.
curl localhost:9090/api/v1/targetsinspectAPI to list all scrape targets and their health. JSON format. Use to programmatically check which targets are up.
curl localhost:9090/api/v1/query?query=upqueryRun a PromQL query via API. Returns JSON. Use for scripting and monitoring checks.
uppromqlBasic PromQL: shows all targets (1=up, 0=down). Paste in Prometheus UI at :9090/graph. First query to run when troubleshooting.
rate(metric_name[5m])promqlPer-second rate of a counter over 5 minutes. Most used PromQL function. Always use rate() on counters — never raw values.
increase(metric[1h])promqlTotal increase over 1 hour. How many requests in the last hour? increase(http_requests_total[1h])
irate(metric[5m])promqlInstant rate (last two samples). More responsive to spikes than rate(). Use for dashboards, not alerts.
histogram_quantile(0.99, rate(hist_bucket[5m]))promqlp99 latency from a histogram metric. Replace 0.99 with 0.95 for p95. The most important latency query.
sum by(label)(metric)promqlAggregate and group by a label. sum by(endpoint)(rate(http_requests_total[5m]))=request rate per endpoint.
predict_linear(metric[6h], 4*3600)promqlLinear prediction: will this metric hit 0 (or any threshold) in 4 hours? Use for disk-full alerts before they happen.
absent(metric)promqlAlert if a metric is missing (target went down). absent(up{job="myapp"})=alert if myapp target disappears.
amtool check-config alertmanager.ymlalertmanagerValidate Alertmanager config file syntax.
amtool alert queryalertmanagerList all currently firing alerts. amtool silence add=silence an alert. Use during planned maintenance.
